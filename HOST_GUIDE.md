# Host guide — one hour with The GIF Break

## The format

Use one host laptop and a TV/projector or screen share. Suggested grouping: teams of 3–5, with 2–8 teams in the page. Each team gets one printed answer sheet and a pen. Players watch and discuss; the host controls the page. Nobody needs to log in or install an app. This is shared-screen play, not synchronized phone multiplayer.

Default thinking time: 45 seconds. Allow roughly 15 seconds for the answer and scoring. A hint can be offered to the whole room after about 20 seconds, without a scoring penalty. The pacing is a facilitation plan, not an automatic one-hour timer; use the buffer to keep discussion moving.

## Before the event

Use review.html on the host screen. All 40 final remote animations were decoded, screened and played in Chrome on 6 October 2026; no source-title captions were found. Check all 40 again from the actual venue/network. Watch every loop, not only the first frame, and tick approvals only after inspection. No host approvals are prefilled. The delivery contains remote links and no local media binaries.

Confirm projector legibility especially for q03, q08, q31, q33 and q34; q33 is only 245 × 160 and should be replaced or voided if unreadable. Check the dim cave in q21, bright effects in q01/q15/q24 and the audience notes for q24/q33/q37. See evidence/VALIDATION.md for the complete dated record.

For an offline media backup, obtain permitted local files and run the local media scanner. Keeping the current project alone does not cache the remote GIFs. Test the browser at projector size, switch tabs to check timer pausing and test full screen. Print one answer-sheet.html per team. Keep ANSWER_KEY.md and review.html off the projector. A second monitor is useful but not required: complete preparation before screen sharing.

Tell the group that clips can move/flash; offer a motion-hidden or alternative participation option. No automatic sound is used. Do not choose a flashing clip merely because the quiz has a Hide motion control.

## Read these rules aloud

“You will see 40 short clips in four rounds. Write the movie, series or source, not just the actor. One correct answer earns one point. Spelling and equivalent translated titles are fine. A film franchise is enough when the answer key allows it; you do not need a year or a sequel number. Round four asks for TV series, not just character names. Question 30 is a video-game wildcard. No searching. We will show a hint to everyone when needed. The host's answer key settles ambiguity.”

Films such as Harry Potter, Pirates of the Caribbean, Toy Story and Rocky allow the broad franchise answer. Finding Nemo and Finding Dory are both accepted for q14 because the source tagging is ambiguous. q39 requires Wednesday/Mercredi; q40 requires The Mandalorian. q30 accepts Red Alert as well as the full title. Announce those category rules upfront rather than changing them after answers arrive.

## Run a question

Load the clip. Once everyone can see it, press Start timer. Offer the hint when appropriate. At zero, ask for pens down; the page does not reveal automatically. Press Reveal answer, then ask teams to raise their sheets or self-report. Toggle each correct team's button once: it awards exactly one point. Press Next.

The timer pauses when the tab is hidden. Hide motion removes the moving image and stops the countdown; Show motion reloads it. Revealed questions stay revealed when revisited. A new question resets to the chosen duration. Saved progress can be resumed after a refresh.

Keyboard: Space starts/pauses the timer, R reveals, H shows the hint, arrows navigate, M hides/shows motion. When a button has focus, Space retains the browser's native button action rather than also toggling the timer.

## Scoring and interruptions

Maximum 40 points. No speed bonus and no half-points: make it social, not argumentative. Score in the page after each answer; verify totals at round breaks. Correct mistaken awards by toggling them off. The page tracks each team/question combination, so revisiting does not double-award.

If a GIF fails, retry once. If it still fails or you discover a spoiler/incorrect source, void it for ALL teams. Its points are excluded and the maximum decreases equally. A shared win is simpler and fairer than an improvised factual tie-breaker.

Use Finish / scores to show the leaderboard, then export scores as a backup. Avoid Reset/New game until the event is done. Ask the room which clip they recognized fastest or which film they would rewatch to fill the final minutes.
